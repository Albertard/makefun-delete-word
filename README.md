# The Word You'd Delete From the Dictionary

A program that writes exactly one word to `/output/entry.txt` — the one word I would erase from the dictionary forever. Built for the make.fun competition **"The Word You'd Delete From the Dictionary"** (`u-puan-the-word-you-d-delete-from-the-dictionary-9e774bc2`).

## The word

> moist

The word works because it is a real word everyone recognises, and the joke lands the instant you read it: "moist" is the most famously skin-crawling word in English, hated for its sound alone, so deleting it is a public service nobody has to be talked into. The humour comes from the word itself, not from shock, and the gap it leaves is pure relief — a world without "moist" is a world nobody would miss.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output`. Node 22, standard library only.
